# 硒泉供水 · Home Assistant 集成

通过「硒泉供水」服务号网页接口读取智能水表数据，并把水费余额、用水量等信息接入 Home Assistant。

## 主要功能

- **传感器**：水费余额、年度用水量、上月水费、最近充值。
- **缴费记录**：传感器附带缴费记录、月度账目等属性（可在选项中选择是否展示缴费记录）。
- **低频轮询**：默认按 3 天（259200 秒）刷新，避免频繁请求。
- **配套卡片**：内置 Lovelace 卡片 `xiquan-water-card.js`，安装后可展示水表信息。

## 配置方式

1. 「设置 → 设备与服务 → 添加集成」，搜索 **硒泉供水**。
2. 填写以下信息：
   - **水表卡号（card_id）**：水表编号。
   - **Cookie**：登录 `xiquanwater.com` 后从浏览器请求头复制的 Cookie。
   - **fans_id**：网页请求中的 `fans_id` 参数。
   - **verify**（可选）：网页请求中的校验参数。
   - **API 地址 / Referer**（可选）：默认指向 `http://www.xiquanwater.com`。
   - **刷新间隔**：单位秒，默认 259200（3 天）。
3. 添加后可在集成「选项」中调整刷新间隔及是否展示缴费记录。

## 注意事项

- 默认刷新间隔较长（3 天），如需更及时的水费变动可自行缩短，但请避免过于频繁请求。
- 本项目为非官方集成，与硒泉供水及 Home Assistant 官方无隶属关系，请自行评估使用风险。

## 安装

### 方式一：HACS（推荐）

1. 打开 HACS → **集成** → 右上角菜单 → **自定义仓库**。
2. 添加仓库地址 `https://github.com/hlhk2017/xiquan_water`，类别选择 **Integration**。
3. 在 HACS 中搜索并安装，然后**重启 Home Assistant**。
4. 到「设置 → 设备与服务 → 添加集成」搜索对应集成名称进行配置。

### 方式二：手动安装

1. 下载或克隆本仓库。
2. 将 `custom_components/xiquan_water` 整个目录复制到 Home Assistant 配置目录的 `custom_components/` 下。
3. 重启 Home Assistant，再在「设置 → 设备与服务 → 添加集成」中添加。
